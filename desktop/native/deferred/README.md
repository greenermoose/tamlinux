# Deferred native integrations

`tamlinux-hibernate-swap` is the developed zram-draining hibernation hook.
Its bytes and executable mode are preserved here while 0.4.4-a tests the
greeter, agent skills and native login. It is outside the installed defaults
tree; the a native package retains the 0.4.3-d sleep-hook set.

The actual-hook regression suite remains `desktop/tests/test_hibernate_swap.py`.
Activation belongs to a later sleep/resume candidate with its own exact
package identity, command naming, mutable recovery and physical proof. Move
the selected hook into the vendor defaults tree and update `origins.json`
when preparing that candidate. Passing these tests is not physical sleep proof.
