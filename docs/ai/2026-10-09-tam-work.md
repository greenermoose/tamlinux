## Change and decisions

Commands that affect how Tamlinux works are now developed in this repository.
The first is `tam-work`, which lets several sessions, people or AI agents,
share Git checkouts by claiming the paths each will edit. It had lived in the
author's private coordination workspace since 2026-10-06, with 28 tests.

- **A product command.** Tamlinux is for developers, so `tam-work` ships to
  users. It lives in a self-contained component, `commands/tam-work/`, with
  `make check` and `make install` (`PREFIX`, `DESTDIR`), ready for a package
  recipe once a version is chosen for release.
- **Configurable locations.** Two hard-coded paths became defaults that
  `TAM_WORK_WORKSPACE` and `TAM_WORK_REGISTRY` (or the existing flags)
  override. With neither set, the paths are unchanged, so existing claims
  keep working.
- **Error prefix.** Errors now start with `tam-work:` instead of `claim:`.
- **The coordination rules stay private for now.** Only the program, its tests
  and a public README moved; the rules are to be published later.

The first plan draft proposed publishing the private coordination rules,
named a registry location the program does not use, and pointed the live
command at a shared working tree. Review corrected these before any work was
delegated.
