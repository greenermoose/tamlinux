# 0.4.3 providers and fresh-session defaults

Development implementation; complete testing readiness remains pending.

The product now owns fresh Hyprland Lua modules, its retained keybindings and
session environment, with explicit consumer override locations and separate
state toggles. Its entry point loads immutable modules, the generated owned
theme, and the selected overrides. The session starts through native UWSM and
Hyprland; Home Manager supplies an opt-in owned configuration and paired
Quickshell selectors. Installing these outputs does not activate a session.

Quickshell startup and IPC select the same immutable provider. Relative provider
paths are rejected. Delivered annotation and screensaver commands select
maintained Tensaku and ttfx builds, rather than an inherited binary channel.

Maintained sources and recorded original hashes are under `desktop/vendor/`:
Tensaku v0.29.0 and ttfx v0.3.2. Their licenses/notices and upstream ancestry
remain intact. Tensaku uses the owned icon font/cache, drops automatic inherited
self-installation, and offers explicit capture-key persistence for an owned
session. The source Apple HID tool v0.6.0 is under `desktop/native/providers/`;
its native installation and device/authorization policy still require proof.
The selected older CLI receives a bounded Arch-profile patch, avoiding a
component upgrade during this assembly work. Retire that patch when the
selected CLI carries the cutover itself.

The icon font removes its inherited glyph alias while preserving character
mapping, outlines and metrics. The annotation TIFF regression independently
checks the encoded file's RGBA values; libtiff's decoder returns associated
alpha, so decoded values alone are not the encoder contract.

Verification completed on immutable development snapshots:

- ttfx: 25 tests and actual deterministic installed frames.
- Tensaku: 228 tests passed, ten upstream skips; independent TIFF file check.
- Product desktop: 450 checks completed successfully, including two existing skips.
- Installed command/output probes: 70 passed with isolated state and recorded IPC.
- Empty-state Lua evaluation covers retained bindings, environment, generated
  theme, personal overrides and owned state toggles. Native Hyprland verifies
  the entry configuration successfully.
- Selected Quickshell: all 32 static module imports register offscreen.
- Compiled/ELF payload and resolved QML collectors pass with the explicit full
  dependency and owned module roots. These are partial I03 cases.

The corrected static inventory includes Lua, desktop entries and native config:
548 runtime files, 65 unresolved lexical names, 71 inherited-name locations,
three undeclared absolute tools, nine pending requirements; readiness false.
Ancestry records and rejection checks are included in those lexical findings;
classify each caller before transferring code or changing behavior.

Delivery records selected signed native providers and retained compositor
patch recipes. A signed stock Arch VM boots through UEFI, completes its
key-only bootstrap without outbound access, and has a clean package/repository
baseline. VM preparation is development infrastructure, not clean-host
acceptance. Still required: complete native ownership/install, all retained
helper calls, effective graphical workflows, migration/new-write recovery,
boot/native transactions and declared physical reference checks. No candidate
letter, assembly pin, live configuration or lifecycle stage changes here.
