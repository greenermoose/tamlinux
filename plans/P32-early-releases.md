# P32: Early Tamlinux releases (Gate A and Blue Sparkler)

- **Phase:** PH01
- **Status:** done (released 2026-10-22 and 2026-11-01)
- **Versions:** 0.4.8 and 0.5.12

## Goal

Establish Tamlinux as a standalone Arch workstation and make its
console-first workflow, input, and desktop defaults ready for daily use.

## Versions

- **0.4.8 (Gate A — released 2026-10-22):** Removed all Omarchy packages
  and paths so Tamlinux stands alone on Arch Linux with Hyprland and
  Quickshell.
- **0.5.12 (Blue Sparkler — released 2026-11-01):** Input usability,
  console-first startup, start menu, monitor control, and Tokyo Night /
  JetBrains Mono defaults (see also [P07-console-first-startup.md](P07-console-first-startup.md),
  [P08-console-monitor-control.md](P08-console-monitor-control.md), [P13-input-usability.md](P13-input-usability.md),
  [P22-start-menu.md](P22-start-menu.md), [P30-theme-system.md](P30-theme-system.md)).

## Acceptance

Both releases shipped and passed daily workstation acceptance.

## Dependencies

Arch Linux, Hyprland, Quickshell (historical baseline).

## Risks

None (completed; recorded retrospectively).

## Open points

None.
