# Retained application icons

`tamlinux-discord.png` preserves the Discord webapp icon shipped by
Omarchy 4.0.4 (`omarchy-settings 4.0.4-1`), originally named
`hicolor/256x256/apps/omarchy-discord.png`. Its bytes are unchanged; Discord
retains its mark. The inherited asset collection is covered by
[`../LICENSE-omarchy`](../LICENSE-omarchy).

Delivery installs it under the owned `tamlinux-discord` hicolor icon name.
The explicit launcher migration changes only the exact inherited icon value;
personal icons and other desktop-entry sections survive. No inherited theme
or icon package is required after migration.
