# Tamlinux system layers

Arch Linux is the operating system on the current Tamlinux workstation. It
provides the kernel, system services and base packages.

Tamlinux is the workstation environment installed on that operating system.
It provides the desktop, commands and configuration used for daily work. It
is not a separate Linux distribution.

Blue Sparkler is the name of the Tamlinux 0.5 cultivar. It names that version
of the Tamlinux environment, not a different operating system.
