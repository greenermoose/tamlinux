## Implementation and checks

`tam-fleet` keeps membership and machine observations in consumer-owned private
repositories. Registration creates explicit profiles without copying a neighbor's
configuration. Local capture is guarded by hostname, clean destinations, a writer
lock and rejected destination symlinks. Success-only reconciliation updates the
index/timestamp and optionally makes exact-path commits; no push or daemon.

`tam-deploy` selects registered local-host profiles, rejects foreign overrides
and updates only that host's BOM. Non-fleet consumers retain their user default.
`tam-nut` is a read-only welcome/hardware helper assembled separately into
bootstrap media; it is not a disk installer.

18 fleet, 47 deployment and 2 bootstrap-helper tests pass. Consumer configuration
builds and physical machine acceptance remain separate evidence. No stage was
advanced or desktop activated by this development work.
