  tags stay; they are no longer the advertised number.
- 0.x remains Omarchy plus Fred's patches and plugins. 1.x means the Omarchy
  dependency is gone; ideas and upstream Quickshell, Hyprland, Wayland, and
  Nix still matter.
- Delivery order: one workstation first, then an installer for a second
  computer. This session does not build the installer.
- Home Manager generation is a local rollback handle. Do not set Tamlinux to
  `0.0.x` where `x` is that generation. Record it at
  `~/.config/tamlinux/generation`.
- Quiet-exit language on the public README: factual current base and intent;
  no controversy statement.
