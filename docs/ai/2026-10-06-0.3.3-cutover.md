## Decisions and implementation

- No part was delegated. The work was shared integration files and a live
  switch, and the one test-sized piece was smaller than its brief would be.
- The session unit runs the whole shell from the pinned deployed copy, with
  the bar's layout, plugin tree, exclusive zone, all outputs, and live
  plugin actions. Live plugin actions were missing from the plan's list; the
  shell's daily bar needs them.
- Rollback keeps the pre-cutover copies of the live-linked compositor and
  menu files beside the previous generation, because those files change
  when the configuration merges, not when the generation switches.
- At the switch the bar drew on all three screens but reserved no space:
  `ExclusionMode.Normal` uses only an explicit `exclusiveZone`, which was
  unset. `ExclusionMode.Auto` reserves the bar's height. The isolated proofs
  had never set the exclusive-zone flag, so this first showed on the
  daily desktop. Fixed in `78115d9`, test-deployed, then pinned.
