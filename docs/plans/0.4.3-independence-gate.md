## Verification and limits

15 gate regressions and 14 collector regressions pass, alongside the prior 21
output-auditor checks, locally and in an isolated offline Nix check. Negative
cases include changed tuple/contract/evidence, missing runners/cases/checks,
post-selection optional exclusions, unresolved QML despite scanner success,
symlink escape/cycle, malformed real ELF, and a compiled inherited-string mutation.
Synthetic passing records verify checker behavior, not desktop acceptance.

The previous display/power slice's five actual immutable outputs yielded 483
payloads and 142 ELF objects. All declared ELF libraries/interpreters resolve.
`tam:bin/tam` contains the inherited host-profile recognition name: the utility
owner must classify/cut over that active compatibility branch. All scanned QML
import paths resolve. 39 plugin records (28 unique Quickshell modules) lack
static-provider registration proof, which must come from the selected pinned
provider and runtime checks. This is reference-host module inspection with
explicit roots, not independent-provider or clean-host proof.

No complete 0.4.3 tuple or required acceptance reports exist. The gate correctly
emits all nine IDs blocked. I01–I08 build/clean-host evidence supports proposing
reference Test; I09 requires actual reference Test and rollback evidence before
Run. Checkers never authorize a stage or package removal.
