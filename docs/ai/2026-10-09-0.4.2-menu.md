# 0.4.2 menu ownership and bounded reloads

- **CLI Tool**: Codex CLI (`codex`) `0.162.0`
- **Model**: `gpt-6.1-sol`
- **Transcript**: Retained privately by the author.
- **Stage**: Develop; isolated proof, no daily activation or version acceptance.
- **Prompts**:
  > Start work on tamlinux 0.4.2. There should be notes for you from a prior codex session.

  > I see a sway process crashed. Was that you that made that happen? Or did it happen spontaneously?

Product defaults and the menu command now live in `desktop/menu/`. The JSONC
lexer preserves strings, supports line/block comments and trailing commas,
and bounds input, rows, fields, aliases and depth. The source reader bounds bytes
before QML sees them. Failed reads/parses retain their source; invalid merged
routes retain the visible model. A status IPC route exposes reload errors.

Nine focused tests exercise malformed/quoted input, bounds, regular-file/FIFO/
UTF-8 behavior, optional extension loading, source retention, merged retention,
recovery and recorded power dispatch in the actual menu service.
An initial private headless Sway launch inside the sandbox failed to open its
socket and aborted in wlroots cleanup. The identical proof passed outside the
sandbox; a socket preflight now prevents that restricted-environment launch.

Workstation integration preserved all 196 merged rows and their ordering,
actions, fields and aliases. Further packaging and configuration evidence is
recorded by their respective owners. Existing unrelated hover work was excluded.
Physical menu acceptance and public publication remain pending.
