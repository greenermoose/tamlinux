## Implemented browser and focus interfaces

Eight maintained commands now have install interfaces and licenses:

| Interface | Behavior and dependency boundary |
| --- | --- |
| `tam-default-browser` | Read/set installed browser XDG handlers; preserve selections and owned notifications. |
| `tam-browser-command` | Read the selected desktop entry into JSON argv without execution. Honor XDG data-home/data-dir precedence, then the traditional Nix user-profile fallback; preserve quoted executable/static arguments. Reject missing, hidden and malformed entries. |
| `tam-launch-browser` | Preserve normal/private launch, HTTPS-handler fallback, owned transient unit and best-effort URL focus. Replace only a standalone `--private` argument, preserving literal URLs. |
| `tam-launch-webapp` | Use supported browser app mode, or the existing Chromium fallback; preserve URL/flag arguments and remove desktop file/URL field placeholders. |
| `tam-hyprland-focus-app` | Focus by class or owned agent initial title; preserve current Lua/legacy Hyprland dispatch routes. Inherited agent-class alias is removed. |
| `tam-launch-or-focus` | Retain class/title focus and the existing single launch-expression interface. |
| `tam-launch-or-focus-webapp` | Quote each webapp argument before handing off the launch expression. |
| `tam-launch-or-focus-tui` | Preserve command/argument boundaries and app ID; reject empty requests. |

Browser resolution follows the [XDG directory rules](https://specifications.freedesktop.org/basedir/latest/)
and the [desktop Exec grammar](https://specifications.freedesktop.org/desktop-entry/latest/exec-variables.html)
for the browser interfaces used here. It preserves literal arguments without
shell execution, expands `%i`, `%c`, `%k`, `%%`, and drops standalone file/URL
and deprecated placeholders; unknown/misplaced fields fail. This is browser argv
resolution, not a general desktop launcher: D-Bus activation, localized name
selection, nested desktop-ID mapping and arbitrary file-opening semantics remain
outside this interface. Applications must provide usable executable desktop
entries through the declared independent host/application boundary.

Delivery wraps Python, XDG utilities, jq, coreutils, grep, systemd, Bash and
setsid as required, resolving sibling helpers from the same package output.
Hyprland, UWSM, terminals and browser applications remain host/application
providers. Menus/default handlers, fonts, Kitty/theme producers and existing
user data still need the final session/migration cutover.

## Compact audit and verification

The delivery auditor supports `--format compact --report /path/full.json`.
The compact view partitions unresolved lexical names into menu-only, shared and
other callers. Full evidence, blockers and exit status remain identical to JSON
mode. It never treats a lexical group as deletion authority or changes readiness.

Sixteen installed browser/focus regressions pass locally and in the Nix command
build. Two targeted regressions reject the original browser/focus-TUI scripts.
Twenty-one auditor regressions pass locally and in Nix. The installed-component
integration and nineteen isolated real-output probes pass, including actual
packaged XDG utilities, quoted browser/static argv, webapp URLs and focus routes.
Browser systemd launch reaches the deliberately unavailable user-bus boundary;
it is not evidence of an actual graphical browser launch.

[Delivery evidence](https://github.com/greenermoose/tamlinux-packages/blob/develop/docs/evidence/0.4.3-menu-launch-closure.json)
retains the exact five output identities and checks. The audit scans 245 runtime
files and reports 101 unresolved lexical command names, down from 103: browser
defaults and webapp launch resolve, with no new unresolved names. The remaining
groups are 66 menu-only, nine shared and 26 other-caller names. Inherited-name
locations remain 54. The additional keybinding launch interfaces do not all
appear in this package audit because packaged session/bindings are still pending.
