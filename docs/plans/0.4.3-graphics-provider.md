# Contained shell graphics provider

A non-NixOS host may expose a Mesa vendor JSON whose relative library name
cannot be loaded from the Nix Quickshell closure. The shell can register its
notification and authorization services while failing to render their surfaces.

Delivery wraps `bin/quickshell` with the locked Mesa EGL vendor JSON and DRI
path. It saves caller values and names its injected keys. `bin/qs` remains the
original paired IPC executable. The wrapper preserves backups when invoked
again inside an already-wrapped environment and removes stale backups otherwise.
No global driver link or user-manager environment setting is required.

Every inheriting shell/plugin QML `Process` restores the caller's graphics
environment using `Util.hostEnvironment`. Every detached launch wraps argv in
`Util.hostArgv`, using the supported Quickshell 0.3.1 API. Explicitly empty
caller values are restored as empty; absent values are removed. Internal marker
variables never reach the child. Processes with closed environments keep their
explicit allowlists. A source inventory rejects uncovered boundaries and
alternate execution APIs that could replace configured process environments.

Verification separates source inventory, real child environments, offscreen
module registration, VM workflows and actual host hardware rendering. Software
VM rendering is not hardware evidence. Before desktop acceptance, verify the
complete delivered shell with no software overrides, surfaces on every output,
paired IPC, visible answered authorization, the complete theme transaction and
a fresh native session. Preserve prior physical acceptance with its original
identities; repeat only checks affected by this correction.

Status: source and real child-environment checks pass; delivery build and
candidate desktop acceptance are tracked independently. Deferred hibernation
changes are excluded from the c-based correction.
