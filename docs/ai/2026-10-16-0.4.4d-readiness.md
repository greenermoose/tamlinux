## Changes

Prepare 0.4.4-d on develop. The native user launcher waits for previous uwsm
units, including deactivating units, and lingering Hyprland processes before
initializing the new session. A 30-second wait or query failure exits with a
journal message. An immutable wrapper named Hyprland invokes start-hyprland
with an explicit compositor path, preserving the uwsm service/plugin ID and
Hyprland desktop name. Package the agreed SysRq mask 244 and update its
recorded source digest.

Retire per-panel IPC handlers and base Panel IPC properties. Retain singleton
service targets and one shell router. No-argument panel calls use the selected
panel or focused output's widget. Update plugin patch versions, proof callers,
port expectations and the live target inventory. Typed direct panel methods
are retired; the changelog records the API change. Include the existing complete
Antigravity quota implementation, including Argon's separate weekly allowance.
