## Key decisions and implementation notes

- The polkit authentication agent and its model are vendored from the
  Omarchy 4.0.4 shell with the MIT notice, as the ninth entry in
  `TAMLINUX_SERVICES` (`polkit`). The prompt, the fingerprint-first flow, the
  wrong-password shake, and Enter/Escape are kept. The model file is unchanged
  apart from its header.
- Changes: `Tam.Commons` and `Tam.Ui` (a new `Color.polkit` token group), the
  agent object path `/org/tamlinux/PolkitAgent`, the `tamlinux-polkit` layer
  namespace, and a lid check that reads `/proc/acpi/button/lid/*/state` in a
  fixed script instead of calling a helper command.
- A read-only IPC target `polkit` (`state`, `ping`) was added so a test can see
  whether this process is the session's agent. It cannot submit or cancel a
  request.
- polkitd accepts one agent per session and Quickshell does not retry a
  refused registration, so the host must start after any other agent has
  gone. This is documented in the desktop README.
