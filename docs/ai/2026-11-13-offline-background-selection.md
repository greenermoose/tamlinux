# Preserve saved backgrounds during offline theme restoration

- **Tool**: Codex CLI `0.169.0`
- **Model**: `gpt-6.1-sol`
- **Transcript**: Retained privately by the author.
- **Request**:
  > Package up and test Tamlinux 0.6.25

Candidate preparation stopped on the theme ownership check before installation.
The offline restore rebuilt the theme before reading the saved background
selection. When derived state was missing, that rebuild replaced the saved
selection with the theme's default image.

Read the portable selection before rebuilding derived state, then resolve it
against the rebuilt theme. When no portable selection exists, retain the
selection generated by the rebuild. Extend the restore regression to check
the selection after another sync, and cover a personal image restored without
derived theme or background state.
